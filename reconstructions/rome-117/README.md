# Rome in 117 CE

This directory is the first place-specific reconstruction package for Worldline Atlas.

## Current state

The package is at **foundation** status. It includes:

- A machine-readable manifest
- A JSON Schema for future packages
- A working study-area viewport
- Search and camera integration for `Rome 117 CE`
- Source, license, temporal-fit, and guardrail records

It does **not** yet include a reconstructed city plan. The study-area rectangle is intentionally marked as a placeholder and is not an ancient wall, administrative boundary, urban footprint, or settlement-density claim.

## Publication rule

A feature cannot move to `published` until it has:

1. A source reference
2. A defensible temporal range
3. An evidence class
4. A confidence value
5. Geometry provenance
6. License and attribution status
7. Human review status

## Planned layer order

1. Monument and place control points
2. Water and topography
3. Walls, gates, and major roads
4. Public monumental footprints
5. Neighborhood and street evidence
6. Residential and commercial massing
7. Vegetation, agriculture, and land cover
8. Pre-rendered historical surface tiles

## Important temporal warning

The Stanford Digital Forma Urbis Romae project documents the Severan Marble Plan, carved in 203-211 CE. It is an invaluable source for later imperial Rome, but it cannot be treated as a direct snapshot of 117 CE. Any continuity inference must be documented feature by feature.
